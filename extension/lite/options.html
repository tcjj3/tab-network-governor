Tab Network Governor

TNG is opt-in by site pattern. The pattern means exactly what you type: omit the scheme to match both HTTP and HTTPS; include a scheme to restrict it; use *. only when you want subdomains.

example.com = HTTP + HTTPS on that host. https://example.com = HTTPS only. *.example.com = subdomains only. Custom ports such as example.com:8080 are supported; Chrome host permission itself is broader than a port, while TNG enforces the port at runtime.
