# Security

Tab Network Governor is intentionally small and local-first.

- It does not collect or transmit browsing data.
- It does not read cookies or authorization headers.
- It does not ship remote code.
- Site access is opt-in through user-authored Site Patterns in the browser extensions.
- The userscript matches HTTP(S) pages for portability but activates only on URLs matched by Site Patterns explicitly stored by the user.

When reporting an issue, do not post credentials, tokens, private request URLs, or unsanitized browsing data.
